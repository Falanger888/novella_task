# ЖК Novella — Landing Page

Адаптивный одностраничный сайт (лендинг) для жилого комплекса Novella. 
Проект выполнен в рамках тестового задания. Основная задача — точная верстка по макету из Figma, реализация интерактивных элементов на чистом JavaScript и адаптация под мобильные устройства.

## ✨ Реализованный функционал

- **Адаптивная верстка**: сайт корректно отображается на десктопах, планшетах и смартфонах (от 375px).
- **Мобильное меню (Бургер)**: кастомное выездное меню с плавной анимацией и блокировкой скролла.
- **Модальное окно**: вызов формы обратной связи по кнопке "Узнать больше". Закрытие по крестику, клику на фон (оверлей) и клавише Esc. Форма имеет кастомные чекбоксы.
- **Слайдер (Карусель)**: самописный слайдер с кнопками навигации (влево/вправо) и точками-пагинацией (индикаторами).
- **Кнопка "Наверх"**: плавный скролл в начало страницы при клике.
- **Плавный скролл**: кнопка "Мышка" плавно скроллит к следующей секции.
- **Умные заглушки (Image Fallback)**: так как исходные картинки весят много и не загружены в репозиторий, написан скрипт, который при отсутствии изображения автоматически подставляет аккуратный SVG-крестик. Если картинки положить в папку `img/`, скрипт отобразит их.

## 🛠 Стек технологий

- **HTML5** (семантическая верстка, доступность форм)
- **CSS3** (Flexbox, позиционирование, кастомные чекбоксы через `::before` / `::after`, медиа-запросы)
- **Vanilla JavaScript** (работа с DOM, обработка событий, создание слайдера с нуля)
- Без использования сторонних библиотек (jQuery, Swiper и т.д.)

## 🚀 Как запустить

1. Скачайте репозиторий или склонируйте его.
2. Откройте файл `index.html` в любом современном браузере.
3. *Примечание: для отображения реальных картинок вместо заглушек, поместите файлы изображений в папку `img`.*

## 📱 Брейкпоинты

- Десктоп: `> 1024px`
- Планшеты: `768px - 1024px`
- Мобильные устройства: `< 768px`
